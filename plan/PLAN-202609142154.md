# pi-web-tools implementation

## Outcome and scope
Implement a TypeScript pi package for pi 0.85.1 (@earendil-works). Always offer Playwright Chromium web_fetch. In OpenAI mode inject hosted web_search into compatible current-model Responses payloads, without registering a local web_search or handling OpenAI credentials. In Brave/Exa mode register local web_search using API credentials from ~/.pi/agent/web_search.json. Do not mutate other tools or install into the user's global pi configuration.

Fetch: isolated contexts, lazy shared browser, bounded concurrency/deadlines, cancellation and shutdown cleanup, rendered HTML extraction using Readability with main/body fallback, Markdown/text, bounded output with private temporary full output, public-network best-effort policy. Search: bounded REST requests, normalized source lists, explicit errors and credential redaction. Native OpenAI: idempotent injection, preserve existing tools/include/tool_choice, conflicts reported, supported Responses API gate and explicit experimental Codex opt-in; no automatic billing fallback. Source changes require /reload.

Exclusions: CAPTCHA/login bypass, personal browser profiles, PDFs/media, batch search, fusion, standalone OpenAI transport, MCP, automatic LLM summarization. Network policy is defense-in-depth, not a DNS-rebinding-proof sandbox. Live subscription support/citation preservation require an authorized live test and must not be claimed from mocks.
